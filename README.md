# Novo Sistema — base visual limpa

Esta é uma adaptação da estrutura visual fornecida pelo usuário, sem autenticação, Firebase ou integrações de dados.

## Executar
Abra `index.html` no navegador ou use um servidor estático local (`python -m http.server 8000`).

## Conteúdo
- `index.html`: estrutura visual, menu responsivo e telas vazias.
- `styles.css`: estilos visuais herdados da base.
- `clean.css`: pequenos ajustes da versão limpa.
- `js/app.js`: apenas navegação e interação visual.

Não há usuários, dados financeiros, código Firebase, configuração de banco ou autenticação. Os ícones Lucide e a fonte Urbanist carregam de CDNs públicos; para funcionamento completamente offline, hospede-os localmente.

A identificação visual e o nome do projeto são provisórios.
